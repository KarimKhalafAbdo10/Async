٢ و ٣. التتابع مقابل التوازي

عمليتان مستقلتان: (A) تحميل الموظفين + استدعاء خدمة الرواتب، (B) إحصاءات الأقسام + خدمة التقارير. تأخير الخدمات الخارجية يحاكي I/O حقيقي.

// تمرير CancellationToken من الـ Controller حتى EF Core public Task<List<Employee>> GetAllAsync(CancellationToken ct) => db.Employees.AsNoTracking() .OrderBy(e => e.Id).ToListAsync(ct); public Task<Employee?> GetByIdAsync(int id, CancellationToken ct) => db.Employees.FirstOrDefaultAsync(e => e.Id == id, ct); await db.SaveChangesAsync(ct);
